# Plagiarism Detector UI Module

## Description
Frontend React component for code plagiarism detection using Google Gemini AI and Abstract Syntax Tree (AST) analysis.

## Features
- Real-time code comparison
- AST-based similarity analysis
- Visual similarity charts and metrics
- Dark mode support
- Responsive design
- AI-powered plagiarism detection

## Dependencies
- React 19.2.4+
- TypeScript 5.8.2+
- Lucide React (icons)
- Recharts (data visualization)
- Google Generative AI SDK

## API Integration
Connects to Google Gemini API for:
- Code analysis
- Similarity detection
- Plagiarism verdict generation
- AST analysis and comparison

## Configuration
See `.env.example` for required environment variables.
